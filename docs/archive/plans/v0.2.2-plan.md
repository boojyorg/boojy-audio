# v0.2.2 Release Plan — UI Polish & Essentials Focus

**Status:** Shipped in v0.2.2 (2026-05-22)

## Context

v0.2.1 shipped with QoL fixes and visual polish. v0.2.2 steps back to focus on getting the essentials right — simplifying the UI, removing visual clutter, and refining the piano roll to feel more like a professional DAW (inspired by FL Studio). Advanced features like automation and sends/returns are deferred to a future version.

---

## Phase 1: Background & Atmosphere (2 items)

### 1.1 Remove star field from arrangement

- **File:** `ui/lib/widgets/timeline_view.dart` (~line 1093)
- **Change:** Remove `const Positioned.fill(child: StarField())` from the timeline Stack. The animated star background conflicts with a professional DAW aesthetic.

### 1.2 Update editor background color

- **File:** `ui/lib/theme/app_colors.dart`
- **Change:** Update the `editor` background token to warm charcoal:
  - Dark theme: `#040412` → `#0E0F14`
  - High Contrast Dark theme: `#020210` → `#0A0B10`
- **Why:** Removes the "outer space" feel. More grounded, studio-like. Grid lines (`#555868`) will have better contrast against the warmer charcoal.

---

## Phase 2: Hide Automation (1 item)

### 2.1 Feature-flag all automation UI

- **File:** `ui/lib/constants/ui_constants.dart`
- **Change:** Add `static const bool enableAutomation = false;`
- **Guard automation UI in:**
  - `ui/lib/widgets/timeline_view.dart` — track automation lane rendering
  - `ui/lib/widgets/track_mixer_strip.dart` — automation button in mixer strip
  - `ui/lib/widgets/piano_roll/piano_roll_controls_bar.dart` — clip automation lane toggle
  - `ui/lib/widgets/piano_roll/piano_roll.dart` — clip automation lane rendering
  - `ui/lib/screens/daw/daw_screen.dart` — automation controller wiring
  - `ui/lib/screens/daw/mixins/` — automation-related mixin callbacks
- **Keep:** All data models, engine code, controllers, painters stay untouched. Only UI visibility changes. Easy to re-enable by flipping the flag to `true`.

---

## Phase 3: Piano Roll Redesign (4 items)

### 3.1 Simplify controls bar

- **File:** `ui/lib/widgets/piano_roll/piano_roll_controls_bar.dart`
- **Keep:**
  - CLIP group: Loop, Start, Length, Time Signature
  - GRID group: Snap, Grid Division, Quantize, Triplet
- **Remove from controls bar:**
  - SCALE group (Root, Type, Highlight, Lock)
  - TRANSFORM group (Legato, Stretch, Reverse)
  - LANES group (Velocity, CC, Clip Automation toggles)
  - Fold/Ghost Notes view toggles
- **Note:** All removed features remain accessible via the piano roll sidebar. Velocity lane stays visible by default (no toggle needed).

### 3.2 Keyboard redesign — FL Studio-inspired

- **File:** `ui/lib/widgets/piano_roll/piano_roll.dart` (`_buildPianoKey` method)
- Black keys shorter (~65px vs 80px white keys), every key labeled, C notes bold.

### 3.3 MIDI notes use track color

- **File:** `ui/lib/widgets/painters/note_painter.dart`
- Replace hardcoded cyan with track's assigned color.

### 3.4 Increase row contrast

- Black key row background `#1E2030` vs white key rows `colors.elevated`.
