# v0.2.3 Release Plan — Foundation & Consolidation

## Context

v0.2.2 shipped UI polish and piano roll refinements. v0.2.3 is an engineering release — users shouldn't notice it as a feature drop. The goal is to make save/load trustworthy, undo consistent, and reduce structural debt so v0.3.0 mixing features (send/return routing) land on solid ground.

---

## Phase 1: Persistence Audit (highest ROI)

### 1.1 Document the split

| Data | Owner | File |
|------|-------|------|
| Tracks, clips, tempo, effects, audio files | Rust engine | `project.json` |
| Panel layout, loop region, track colors, view state | Dart UI | `ui_layout.json` |
| Automation (UI hidden) | Both | engine + `ui_layout.json` |

Add this table to [ARCHITECTURE.md](../ARCHITECTURE.md) under a new **Project Persistence** section.

### 1.2 Centralize UI persistence checklist

- **File:** `ui/lib/services/project_persistence.dart` (new)
- **Change:** Single module that defines which UI fields are saved/loaded via `UILayoutData`. Project managers call into it instead of scattering field lists.
- **Why:** Prevents repeat of v0.2.1 bugs (track colors, loop region not persisting).

---

## Phase 2: Integration Tests (3 golden paths)

Add `ui/integration_test/` using Flutter's `integration_test` package:

1. Create project → add MIDI track → save → reload → assert track count
2. Edit note in piano roll → save → reload → assert note data
3. Move clip → undo → clip returns (after Phase 3 undo fixes)

Prefer native smoke tests with the real engine where feasible; document stub limitations in verification.

---

## Phase 3: Undo Audit

Audit top actions **not** going through `UndoRedoManager` / `Command`:

- Timeline clip drag/trim — `ui/lib/widgets/timeline_view.dart`
- Device chain / effect param drags — `ui/lib/widgets/device_chain/device_chain_view.dart`
- Track mixer fader/pan — `ui/lib/widgets/track_mixer_panel.dart`

Fix the **top 3–5** by reusing existing command classes where they exist.

---

## Phase 4: Timeline Decomposition (start small)

First extraction from `timeline_view.dart` into `ui/lib/widgets/timeline/`:

- `timeline_gesture_layer.dart` — drag/trim/pan handlers
- `timeline_track_list.dart` — track rows + headers wiring

Target: cut ~800–1200 lines from `timeline_view.dart`. Do **not** big-bang refactor in one PR.

---

## Phase 5: CI & Hygiene

- **File:** `.github/workflows/ci.yml` — add `windows-latest` job: `flutter analyze`, `flutter test`, `cargo clippy` (no VST3 build)
- **File:** `.gitignore` — add `engine/vst3_host/build_win/`
- Delete confirmed orphan files (see codebase review): `star_field.dart`, `utils/app_colors.dart`, `mixer_panel.dart`

---

## Out of Scope (v0.3.0+)

- Send/return routing
- Ghost notes in piano roll
- Full `timeline_view.dart` refactor (Phase 4 is phase 1 only)
- Removing `sampler_editor/` (dormant WIP for v1.0 Boojy Sampler)
- Removing automation backend (hidden by `UIConstants.enableAutomation`)
