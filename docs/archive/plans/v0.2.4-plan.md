# v0.2.4 Release Plan — Finish the Foundation

## Context

v0.2.3 shipped persistence centralization, golden-path integration tests, and a partial undo audit. v0.2.4 completes the consolidation work deferred from that release: Windows CI coverage, the first timeline decomposition pass, and remaining undo gaps. Users won't see a feature headline — the payoff is confidence before v0.3.0 send/return routing lands.

---

## In Scope

### Windows CI

- **`.github/workflows/ci.yml`** — `windows-latest` jobs for `flutter analyze`, `flutter test`, and `cargo clippy` (no VST3 build)
- **`.gitignore`** — ignore `engine/vst3_host/build_win/`

### Timeline decomposition (phase 1)

Extract from `timeline_view.dart` into `part` files under `ui/lib/widgets/timeline/`:

- `timeline_gesture_layer.dart` — clip drag/trim/resize, eraser, split preview, MIDI move undo commits
- `timeline_track_list.dart` — track rows, automation lanes, empty-area drop targets

Target: ~3800 lines moved; `timeline_view.dart` reduced to ~1200 lines. Zero behavior change.

### Undo gaps

- VST3 parameter drags in plugin UI → `SetEffectParameterCommand`
- Clip-move undo integration test (golden path #3 from v0.2.3 plan)
- Engine fix: `set_clip_start_time` syncs global MIDI clip storage when repositioning

### Release hygiene

- v0.2.3 tagged and documented (CHANGELOG, ROADMAP, archived plan)

---

## Out of Scope (v0.3.0+)

- Send/return routing UI
- Ghost notes in piano roll
- Full `timeline_view.dart` refactor (only phase 1 extraction)
- Automation lane undo (UI still hidden)
