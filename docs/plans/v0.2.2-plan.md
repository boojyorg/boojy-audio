# v0.2.2 Release Plan — UI Polish & Essentials Focus

## Context

v0.2.1 shipped with QoL fixes and visual polish. v0.2.2 steps back to focus on getting the essentials right — simplifying the UI, removing visual clutter, and refining the piano roll to feel more like a professional DAW (inspired by FL Studio). Advanced features like automation and sends/returns are deferred to a future version.

---

## Phase 1: Background & Atmosphere (2 items)

### 1.1 Remove star field from arrangement

- **File:** `ui/lib/widgets/timeline_view.dart` (~line 1093)
- **Change:** Remove `const Positioned.fill(child: StarField())` from the timeline Stack. The animated star background conflicts with a professional DAW aesthetic.

### 1.2 Update editor background color

- **File:** `ui/lib/theme/app_colors.dart`
- **Change:** Update the `editor` background token to warm charcoal:
  - Dark theme: `#040412` → `#0E0F14`
  - High Contrast Dark theme: `#020210` → `#0A0B10`
- **Why:** Removes the "outer space" feel. More grounded, studio-like. Grid lines (`#555868`) will have better contrast against the warmer charcoal.

---

## Phase 2: Hide Automation (1 item)

### 2.1 Feature-flag all automation UI

- **File:** `ui/lib/constants/ui_constants.dart`
- **Change:** Add `static const bool enableAutomation = false;`
- **Guard automation UI in:**
  - `ui/lib/widgets/timeline_view.dart` — track automation lane rendering
  - `ui/lib/widgets/track_mixer_strip.dart` — automation button in mixer strip
  - `ui/lib/widgets/piano_roll/piano_roll_controls_bar.dart` — clip automation lane toggle
  - `ui/lib/widgets/piano_roll/piano_roll.dart` — clip automation lane rendering
  - `ui/lib/screens/daw/daw_screen.dart` — automation controller wiring
  - `ui/lib/screens/daw/mixins/` — automation-related mixin callbacks
- **Keep:** All data models, engine code, controllers, painters stay untouched. Only UI visibility changes. Easy to re-enable by flipping the flag to `true`.

## Phase 3: Piano Roll Redesign (4 items)

### 3.1 Simplify controls bar

- **File:** `ui/lib/widgets/piano_roll/piano_roll_controls_bar.dart`
- **Keep:**
  - CLIP group: Loop, Start, Length, Time Signature
  - GRID group: Snap, Grid Division, Quantize, Triplet
- **Remove from controls bar:**
  - SCALE group (Root, Type, Highlight, Lock)
  - TRANSFORM group (Legato, Stretch, Reverse)
  - LANES group (Velocity, CC, Clip Automation toggles)
  - Fold/Ghost Notes view toggles
- **Note:** All removed features remain accessible via the piano roll sidebar. Velocity lane stays visible by default (no toggle needed).

```text
BEFORE (5 groups, ~20 controls):
[Loop] Start [1.1.1] Len [5.1.1] [4/4] | [Snap 1/16] [Q] [T] | [C] [Maj] [H] [L] | [Legato] [Stretch] [Rev] | [Vel] [CC] [Auto]

AFTER (2 groups, ~8 controls):
[Loop] Start [1.1.1] Length [5.1.1] [4/4]  |  [Snap] [1/16] [Quantize] [Triplet]
```

### 3.2 Keyboard redesign — FL Studio-inspired

- **File:** `ui/lib/widgets/piano_roll/piano_roll.dart` (`_buildPianoKey` method)
- **Black keys shorter:** ~65px wide (vs 80px white keys). The remaining ~15px on the right of black key rows shows the white key color behind, creating a visual keyboard shape.
  - White keys: full 80px gutter width, `colors.elevated` bg
  - Black keys: ~65px width, `colors.standard` bg (darker)
- **Every key labeled:** All 12 notes per octave show their name (C4, C#4, D4, etc.)
  - C notes: 9pt semi-bold (octave marker emphasis)
  - Other notes: 8pt regular weight
  - Black key text: `colors.textMuted`
  - White key text: `colors.textSecondary`

```text
KEYBOARD (80px gutter)
│ C5              │  ← white, full 80px, bold "C5"
│ B4              │  ← white, full 80px
│██ A#4 ██│       │  ← black, 65px + exposed white area
│ A4              │
│██ G#4 ██│       │  ← black, 65px
│ G4              │
│██ F#4 ██│       │  ← black, 65px
│ F4              │
│ E4              │
│██ D#4 ██│       │
│ D4              │
│██ C#4 ██│       │
│ C4              │  ← white, bold "C4" (octave marker)
```

### 3.3 MIDI notes use track color

- **File:** `ui/lib/widgets/painters/note_painter.dart`
- **Change:** Replace hardcoded cyan (`#00BCD4`) with the track's assigned color.
  - Pass track color to `NotePainter` from the piano roll widget
  - Velocity-based HSL brightness adjustment continues to work with any base hue
  - Selected notes: keep 2px white interior border
  - Note name labels: white text on colored background (unchanged)

### 3.4 Increase row contrast

- **File:** `ui/lib/widgets/piano_roll/piano_roll.dart` (where `blackKeyBackground` / `whiteKeyBackground` are set)
- **Change:** Black key row background from `colors.standard` (#272A38) → `Color(0xFF1E2030)` (darker). White key rows stay `colors.elevated` (#292B36). Creates ~4 L* difference instead of the current ~2.

## Phase 4: Button Visual Polish (3 items)

### 4.1 Tool buttons stand out

- **File:** `ui/lib/widgets/editor_panel.dart` (`_buildToolButton` method)
- **Current:** 28x28 boxes with `colors.dark` (#2C2C32) bg — blends into the darkest toolbar.
- **Change:**
  - Inactive: `colors.surface` (#353845) bg + 1px `colors.divider` (#3A3D4A) border
  - Active: `colors.accent` (#40B3E8) bg, no border (unchanged)
  - Temp active (modifier held): `colors.accent` at 50% opacity, no border (unchanged)

### 4.2 Tab buttons ([Synth] [MIDI] [Effects]) stand out

- **File:** `ui/lib/widgets/editor_panel.dart` (`_buildTabButton` method)
- **Current:** Selected = solid accent bg, Unselected = transparent (invisible against toolbar).
- **Change unselected tabs:**
  - Background: `colors.surface` at 50% opacity
  - Border: 1px `colors.divider` at 50% opacity
  - Text/icon: `colors.textSecondary` (unchanged)
- Selected tabs keep accent bg + white text (unchanged).

### 4.3 Collapse chevron matches tab style

- **File:** `ui/lib/widgets/editor_panel.dart`
- **Change:** Apply the same unselected-tab styling (surface bg 50%, divider border 50%) to the expand/collapse chevron button so it matches the adjacent tab buttons.
