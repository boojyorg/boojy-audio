# v0.3.0 Release Plan — Send/Return + Hidden Master Row

## Context

Today you can add reverb **on each track separately** — more CPU, inconsistent sound, harder to mix. v0.3 adds **shared effect buses**: route multiple tracks through one reverb or delay, adjust wetness per track, hear it in playback and export.

The mixer gets a **⚡ FX button** on every strip — one entry point for “effect on this track” (insert) or “shared effect” (send). Send controls appear **only when they exist**; empty projects stay clean.

A second polish item: the **Master timeline row** (big empty blue strip at the bottom) hides by default. It appears when you add master automation or explicitly show it from the View menu.

**Supersedes:** [v0.2-plan send section](../archive/plans/v0.2-plan.md) (`[+ Bus]` preset dialog → replaced by ⚡ FX picker).

---

## Design decisions

| Decision | Choice | Alternative cost |
|----------|--------|------------------|
| FX entry | ⚡ on every strip (insert + shared) | Separate `[+ Bus]` button — extra discovery step, two mental models |
| Send row layout | Inline rows under fader when sends exist | Collapsed sends — saves height but hides routing during mix |
| Return placement | Pinned mixer section before Master; **no timeline rows** | Return rows in arrangement — visual clutter for non-clip tracks |
| Height sync | Timeline row grows with **blank padding** when sends exist | Mismatch breaks scroll sync between timeline and mixer |
| Shared sends | Built-ins only (reverb, delay, eq, …) | VST3 shared buses — heavy scope (plugin identity, state, PDC) |
| Bus dedup | One bus per effect **type** per project | Multiple reverbs — deferred; avoids bus sprawl in v0.3 |
| Pre/post | Post-fader only (hardcoded) | Pre/post toggle — UI + solo edge cases; v0.4 |
| Master ⚡ | Insert FX only on Master (no sends from Master) | Sends on master — rare, confusing |
| Master row | Hidden unless automation / View toggle / load with automation | Always visible — wastes arrangement space |
| Default send level | **-20 dB (~10%)** at creation | 0 dB — too wet; users clip returns immediately |
| Return FX wet | **100% wet** on bus creation | Stock reverb defaults 30% wet — wrong for parallel send |

---

## Defaults (locked)

- New projects: **no pre-loaded buses**
- New send amount: **-20 dB**
- All sends: **post-fader** (`pre_fader = false` always in v0.3)
- Returns route to **Master only** (no return→return)
- Second “Shared → Reverb” on any track routes to **existing** Reverb return (dedup by effect type string: `reverb`, `delay`, `eq`, …)

## UI components

### Strip row 1 — ⚡ next to MSR

```
┌─ 🥁 2 Drums           M  S  R   ⚡   ◯ ┐
│  -6.0 dB    ════●═════════════         │
└────────────────────────────────────────┘
```

- `⚡` shows `+` on hover/focus. Click → FX picker.
- `◯` = pan knob (unchanged).
- At compact strip heights, ⚡ stays high in drop order (after M/S/R if possible).

### Strip with sends — rows only when sends exist

```
┌─ 🥁 2 Drums           M  S  R   ⚡   ◯ ┐
│  -6.0 dB    ════●═════════════         │
│   Reverb  ●20%                    [×]  │
│   Delay   ●10%                    [×]  │
└────────────────────────────────────────┘
```

- Each send row: label (bus name) + amount knob + remove.
- Drag knob → adjust; double-tap → **0** (off, row stays); `[×]` → remove send (bus stays).
- Adding/removing sends updates **`clipHeights[trackId]`** for timeline + mixer (timeline shows blank padding below clip area).

### Return strip — pinned section before Master

```
┌─ 🔊 Reverb         RETURN   M  S   ◯   ┐
│  0.0 dB     ════●═════════════         │
└────────────────────────────────────────┘
```

- No R, no input selector. Pan + fader + M/S.
- Double-click name to rename. Right-click → delete (removes all sends pointing here; **undo as composite**).
- Right-click empty return (zero incoming sends) → delete option.
- Not draggable with regular tracks. Not in timeline `trackOrder`.

### FX picker (from ⚡)

```
┌─────────────────────────────┐
│  Add effect — Drums         │
├─────────────────────────────┤
│  ◉ On this track            │
│  ○ Shared (send)            │
├─────────────────────────────┤
│  🔍 Search effects...        │
│  • Reverb                   │
│  • Delay                    │
│  • EQ                       │
│  • Compressor               │
│  • Chorus                   │
│  • Limiter                  │
└─────────────────────────────┘
```

- Default mode: **On this track** → existing insert path (`addEffectToTrack`).
- **Shared (send):** built-ins only; Reverb/Delay listed first. If type already has a return → add send to existing bus + create send row. Else → `create_return(type)` + send at -20 dB.
- **Master strip:** picker shows insert mode only (no Shared toggle).
- VST3: insert-only via ⚡ (or drag from library as today). Not in Shared list.


## Master timeline row — hidden by default

**Current:** Master always rendered as last arrangement row (empty blue strip).

**New:** Master row **conditional**. Visible when:

1. Project loads with existing **master volume/pan automation**, or
2. User right-clicks Master mixer strip → **Add automation** (creates lane + reveals row), or
3. **View → Show Master Row** (per-project escape hatch)

When all master automation is removed → row **auto-hides on next save/load** (not mid-session).

Return tracks: **mixer-only in v0.3** — no timeline rows even if return automation exists (edit via mixer Auto lane if enabled).

## Interaction summary

| Action | Result |
|--------|--------|
| ⚡ → On this track → Reverb | Insert on track FX chain (today’s behavior) |
| ⚡ → Shared → Reverb (no bus yet) | Create Return + reverb @ 100% wet + send @ -20 dB |
| ⚡ → Shared → Reverb (bus exists) | Add send row @ -20 dB to existing return |
| Right-click → Send to Reverb | Same as shared pick when bus exists |
| Drag send knob | Adjust amount (undo on drag end) |
| Double-tap send knob | Amount → 0 |
| `[×]` on send row | Remove send; bus remains |
| Delete return | Remove return + all sends to it (single undo) |
| Solo track | Non-solo tracks silent **including their direct out**; sends from solo’d track still feed returns (document in audit; match common DAW behavior) |
