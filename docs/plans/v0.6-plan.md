# v0.6 — "Sound" Plan

> Theme set by the [2026-06-05 review chain](../reviews/triage_2026_06_05.md) (canonical decisions)
> — **not** the raw reports. Drum-kit detail lives in the approved implementation plan
> (engine PR #44 + editor PR #45 already merged from it); this doc is the version-level scope.

## Context

v0.6 is the release where a beginner can make their **first beat from scratch** — and where the
sounds and clip tools they reach for next actually work. Today the drum kit exists but opens
empty (no bundled sounds), the Reverse toggle on samples does nothing, automation is built but
switched off, there's no way to hear yourself while recording, and joining clips silently bypasses
undo. v0.6 closes those gaps, then spends the rest of the cycle on the "Calm & Legible" UI ledger
— small visible trust fixes (a playhead you can see, lane separators that exist, tooltips on
M/S/R) landed in steady batches with check-ins between.

**Deliberately not in v0.6:** stock instruments (B-1) — Tyr's pre-1.0 bottleneck is not
instruments; explicitly deferred at triage. The built-in synth stays one-oscillator simple.

## Design decisions (settled 2026-06-05 triage + 2026-06-06)

- **Starter kit = 8 CC0 sounds, sourced online, Tyr approves before commit.** Kick, snare,
  closed hat, open hat, clap, low tom, mid tom, crash. Licence documented in a LICENSES note.
  Alternative (Tyr records his own) deferred — would block PR3; can swap later release.
- **Join clips lands as proper Commands** — subsumes the C37/C50 undo-bypass bugs
  (fix-by-rewrite, not twice).
- **Normalize deferred to v1.0** (Tyr, 2026-06-08) — was scoped as non-destructive clip gain
  (peak scan → gain to −1.0 dBFS, stored per-clip, applied at playback/export, toggle-able,
  undoable); that design carries forward when it's picked back up.
- **Hide the High Contrast theme** (keep the definition) — token leaks mean it renders broken
  surfaces today; same "broken-promise control" logic as the dead Reverse toggle. Re-expose
  after the token ramp-down.
- **Remove the piano-roll chord palette** (`K` toggle) — keyboard-only, zero discoverability;
  delete rather than promote (decided 2026-06-06, see ROADMAP).
- **Mixer: small additive fixes in, §6.B layout mockup parked.** Unity-gain tick (H6),
  peak-hold (H7), tooltips (H8), dB sends (M8) land in a normal batch; the strip *restructure*
  waits for a design conversation first.
- **UI ledger lands in small batches, verify between** — not one mega-PR; each batch is
  walkthrough-testable. Loop region is orange (not "gold" — report terminology corrected).

## Verification (manual, `fvm flutter run -d macos`)

1. **First beat:** Library → Drum Kit → pads come pre-filled with the starter sounds; click
   steps across kick/snare/hat → press play → you hear a beat. No file-picking required.
2. **Quick wins:** record an automation gesture and see it play back; toggle Reverse on a sample
   and hear it reversed; enable monitoring and hear your input while armed.
3. **Join:** select two MIDI clips → join → one clip; Cmd+Z splits them back. Same for audio.
4. **UI batches:** playhead clearly visible over a blue selection; piano-roll lanes separable at
   a glance; mixer faders show a unity tick and M/S/R explain themselves on hover; narrow window
   never shows the red overflow banner.
5. **Removals:** `K` in the piano roll does nothing; High Contrast absent from settings; existing
   projects that used either still load fine.

Gates per repo CLAUDE.md before each PR; Windows smoke test repeats at release per the checklist.
