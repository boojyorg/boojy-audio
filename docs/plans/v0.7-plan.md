## Context

v0.7 makes Boojy *feel* like one finished instrument instead of a polished shell with rough
pockets. Four things change for someone using the app:

1. **The Light theme actually works.** Today several surfaces (file-drop zone, selected device
   borders, snap/quantize popups, parts of settings) hardcode dark-theme colours and render
   broken on Light. After v0.7, switching themes is safe everywhere.
2. **The most-touched controls respond instantly.** The position and tempo readouts currently
   wait ~300 ms before reacting to a tap, and a single misclick on a fader teleports the volume.
   All three footguns go away.
3. **The mixer and piano roll explain themselves.** Peak-hold ticks, a 0 dB unity mark,
   icon+tooltip Mute/Solo/Record/Monitor, sends shown in dB, visible piano-roll lane structure,
   a tool-mode badge, and app-wide Affinity-style tooltips — the cues a beginner navigates by.
4. **Every built-in device wears the same chrome.** Synth, Sampler, Drum Kit, EQ, and the
   effects get one shared shell (header + power dot + collapse, a visual, 2–3 hero knobs, a
   fixed MIX knob) — plus one popup/dropdown system (filled value chips) and a consistent
   hover/press language, so the whole app reads as one product.

Plus the hardware papercuts: MIDI keyboards connect when plugged in mid-session, and Windows
users get a working "Check for Updates".

## Design decisions

- **Theme correctness before any further polish.** Every painter/popup colour becomes
  theme-sourced or `required`. *Alt (patch visually as found): every future Light fix builds on
  sand and the theme switch keeps silently failing in pockets.*
- **Footguns first, visuals second (X1/X2/M1).** *Alt: the bar keeps feeling laggy no matter how
  good it looks — "feel" is the theme's first word.*
- **One device shell, designed before built.** The shell (per the ui-ux §7.3 mockup) is a real
  design task and the milestone's bulk; Synth/Sampler/Drum Kit/EQ/effects all adopt it. *Alt
  (patch each card): the "three metaphors in one chain" gestalt survives and we fix symptoms
  one at a time, forever.*
- **One popup system everywhere.** Filled-chip value dropdowns (Tyr's pick), the same compact
  panel for right-click menus, value chips in the piano-roll toolbar. *Alt: three menu dialects
  persist and every new surface picks one at random.*
- **Editor min-height = adapt-then-clamp (option c).** Devices compress to a compact floor
  (graph collapses first), then a hard min stops further shrink. *Alt (internal scroll):
  scroll-in-scroll, bad on tablets.*
- **Inert controls either work or disappear.** Swing: verify it audibly changes playback → keep
  as a one-shot action, else hide. Ghost notes: wire it if small while the piano roll is open,
  else hide the toggle. *Alt: named controls that do nothing keep eroding trust.*
- **Hardening stays a background track.** Guardrails (EH-2..5, EH-9, EH-15, EH-17) ride along as
  a half-day, not a headline. Codebase-review reruns at the END of the cycle to measure.
- **Steady small batches with walkthrough check-ins** — batch → gates green → Tyr's manual
  walkthrough → PR. No big-bang UI branch.

## Verification (manual walkthrough, per batch on `fvm flutter run -d macos`)

- **Slice 1:** switch to Light → file-drop zone, selected device border, snap/quantize popups
  all legible (no dark-on-dark / white-on-white); `Cmd+Shift+T` cycle never lands on a broken
  High-Contrast variant. Tap position/tempo readouts → instant response. Single-click a fader
  body → volume does **not** jump.
- **Slice 2:** play a loud clip → peak-hold tick freezes ~1.5 s; unity tick visible at 0 dB;
  hover M/S/R/I → plain-language tooltips; send reads "−20 dB" not "10%". Piano roll: visible
  white-key separators, clearly darker black-key rows, "C#5" keeps its sharp, root band only
  with Scale Highlight on. The active tool is read from the editor toolbar's highlighted button
  (the proposed canvas badge was dropped as redundant).
- **Slice 3:** every dropdown is a filled value chip opening the same compact menu; right-click
  menus match it; Quantize flashes (no stuck outline); narrow the window → top-bar groups drop
  cleanly into overflow, readout never goes sub-readable; all three settings dialogs share one
  chrome and dim the background equally.
- **Slice 4:** open Synth, Sampler, EQ, Reverb → identical header chrome, fixed MIX knob, a
  collapse triangle that shrinks to a header strip; shrink the editor → devices compact
  gracefully, then stop (no "BOTTOM OVERFLOWED"). Sampler waveform starts at the left edge.
  Plug a MIDI keyboard in **mid-session** → it plays within ~2 s, no settings visit. On
  Windows: "Check for Updates" responds. Play unarmed, then hit Capture MIDI → the phrase you
  just played lands as a clip. Cmd+D on an **audio** clip duplicates it. Legato extends selected
  notes to the next note's start.
