## Verified bugs — ALL FIXED in batch 2 (same branch, 2026-06-09)

- [x] **Corner artifact (systemic):** border+radius+clip shaved the stroke at corner arcs. Fixed
  on metronome (inner fills rounded to radius−1, clip removed) and DeviceBox (ClipRRect on the
  body at inner radius). Rule codified in `.claude/rules/flutter-ui.md`.
- [x] **Editor header heights:** instrument card now `HeaderMode.full24` (same as effects);
  legacy `SynthesizerPanel` header (54px SYNTHESIZER + no-op ✕ + drag-out) deleted outright —
  the ✕ was wired to `onClose: () {}`.
- [x] **"Synth"/"SYNTHESIZER" naming:** tab + device header both say "Synthesizer".
- [x] **Synth level meter blank:** built-in synth (no effectId) now meters the track output via
  `getTrackPeakLevels` under a sentinel key. Note: shows post-chain track level, not isolated
  instrument output — engine-side instrument tap would be the "proper" fix if it ever matters.
- [x] **Volume fader sync:** chain fader now writes `track.volumeDb` into the mixer state via
  `mixerKey` (was a bare setState) — live both ways.
- [x] **"+ Audio" icon** → `BI.equalizer` (matches library Samples).
- [x] **Name vs "In 1" chip:** row 1 sheds the input chip first at narrow widths (LayoutBuilder
  estimate); name keeps priority. Input selection still reachable by widening the mixer.
- [x] **Ruler/zoom collision:** zoom buttons got an opaque pinned backing (mirrors the left
  orientation chip). Shared widget — also improves the Piano Roll ruler.
- [x] **EQ dead knobs:** effective selection falls back to band 0 — knobs never show "–" while
  bands exist. Clicking empty graph now re-selects band 1 instead of deselecting.
- [x] **"+" add-device slot** now full chain height, aligned with device cards.
