# Review screenshots (staging)

Drop current-build window screenshots here (`*.png`) **before** running the `ui-ux-review`
workflow; its readers list this folder and look at every PNG. The PNGs are gitignored: they are
disposable input, so delete them after the review. Release screenshots live in `docs/screenshots/`.

Why a fixed folder: workflow `args` and pasted-image paths don't reliably reach the readers.
