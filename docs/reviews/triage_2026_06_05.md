## B-6 normalize — design sketch (for discussion)

Non-destructive clip gain, not sample rewriting: engine scans the clip's samples for peak
(one pass, offline), computes the gain that brings peak to a target (−1.0 dBFS), stores it as a
per-clip normalize gain applied at playback/export. UI: right-click clip → "Normalize", wrapped
in a Command (undo = clear the gain). Needs one new FFI pair (`normalize_audio_clip_ffi` /
clear) + persistence of the gain in project.json. Toggle-able (re-running un-normalizes).
